## Back-Rave

#### pasos para correr el proyecto

1. Clonar el repositorio
2. Instalar dependencias ```npm install```
3. Crear el archivo de configuración .env copiando el archivo .env.template y modificando los valores de la variable de entorno
4. Correr el proyecto ```npm run start:dev```
